# 鲲鹏 WGCNA 分析

WGCNA 不是差异表达的附属作图。先判断数据规模和设计是否适合建网，再执行可复现的网络分析。

## 执行顺序

1. 读取 `references/input-contract.md`，确认表达矩阵的数值类型、归一化方式、基因过滤规则和性状定义。
2. 运行：

   `python scripts/preflight.py --expression <expression.tsv> --traits <traits.tsv> --report <project>/00_preflight/report.json`

3. 阻断重复基因/样本 ID、非数值表达值、样本无法对齐、性状无变异等问题。样本量偏小时只给风险提示，不伪装成稳定网络。
4. 依据 `references/workflow.md` 完成异常样本检查、软阈值诊断、网络类型选择、模块识别与合并、模块-性状关系和候选基因分析。
5. 输出参数、随机种子、样本树、软阈值诊断、模块成员、模块特征基因、关联统计、完整 R 会话信息和日志。

## 门禁

- 不直接使用原始整数 counts 建网；先采用与设计匹配的方差稳定化或标准化表达。
- 不自动把任意 `R²` 阈值当作唯一正确答案；同时查看平均连接度和网络可用性并记录选择理由。
- 未控制批次、群体结构或明显协变量时，不把模块-性状相关解释成生物机制。
- 枢纽基因必须说明其定义、模块归属、模块成员度及外部证据；不能仅凭网络图位置认定。
