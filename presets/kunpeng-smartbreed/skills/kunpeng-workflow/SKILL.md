# 鲲鹏智育 · 组学与育种数据分析工作流

本技能用于将经过验证的基因组学、转录组学、GWAS、全基因组选择（GS）等分析流程，以受控方式编排执行。

## 工作流执行步骤

1. **需求理解**：将用户的自然语言研究目的转化为明确的分析任务（差异表达分析 / 变异检测 / 关联分析 / 育种值预测等）。
2. **输入确认（必须逐项确认）**：
   - 物种与参考基因组版本
   - 实验分组与比较设计
   - 表型定义与单位
   - 样本清单与命名
   - 计算资源与运行方式
3. **流程推荐**：从白名单流程库中选择匹配的流程与参数模板，说明选择理由。
4. **执行**：只调用审批后的分析模块，不执行任意命令、不自由生成生产代码；关键步骤前征求用户确认。
5. **记录与产出**：沉淀软件版本、参数、输入输出路径、日志、质量控制图和结果文件，形成可复现实验记录。

## 白名单与审批

- 分析模块清单、参数模板和育种模型必须经过"流程准入"：在真实数据上完成验证并经负责人确认后才可用于生产。
- 新流程 / 新参数：先在小样本上验证，再申请进入白名单。
- 任何超出白名单的命令执行须暂停并向用户说明风险，等待批准。

## 可复现记录格式

每次分析输出一个记录文件（推荐 YAML/JSON），包含分析名称、物种与参考基因组版本、软件及版本清单、关键参数、输入输出清单、质量控制结果、日志路径与结果摘要。

示例结构：

    analysis: 分析名称
    species: 大黄鱼 Larimichthys crocea
    reference_genome: 版本与来源
    software: [{name: STAR, version: "2.7.x"}, {name: featureCounts, version: "2.0.x"}]
    parameters: {关键参数键值}
    inputs: [样本/数据文件清单]
    outputs: [结果文件清单]
    quality_control: [QC 通过项]
    logs: [日志路径]
    summary: 结果摘要

## 常见分析提醒

- RNA-seq：先评估数据质量（fastqc/multiqc），明确比对工具与注释版本，差异表达注意多重检验校正（FDR）。
- GWAS：确认群体结构校正（PCA/混合模型）、亲缘关系矩阵与显著阈值；报告效应量与置信区间。
- 基因组选择：说明训练群与验证群划分、预测模型（GBLUP/Bayes 类）、交叉验证策略与预测准确性指标。
- 流程失败：保留原始日志，定位失败步骤，给出可复现的修复建议，不掩盖错误。

## 边界

- 分析结论以输出文件为准，模型只负责解释；关键统计结果与育种推断须由领域专家复核。
- 涉及参考基因组、样本清单等关键输入不明确时，先确认再执行，避免错误计算。
