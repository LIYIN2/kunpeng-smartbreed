# 鲲鹏知识库登记与治理规范

## 学生添加新知识的标准流程

1. 保留原始文件：将 PDF、DOCX、表格导出或会议纪要放入受控位置，不覆盖原件。
2. 复制 `templates/knowledge-entry.md`，文件名使用 `YYYY-MM-DD-主题.md`。
3. 填完元数据和原文定位，将“事实”、“专家意见”、“整理者解释”、“对大黄鱼的推断”分开。
4. 初次提交一律为 `status: draft`；由负责人核对原文后改为 `reviewed`。
5. 审核通过后同步到三处：
   - `knowledge/md/`
   - `skills/kunpeng-knowledge/references/`
   - `presets/kunpeng-smartbreed/knowledge/`
6. 涉及联系人、未公开数据、采购价格、育种决策的内容标记 `sensitivity: internal` 或 `restricted`，不进入公开发行包。

## 字段规则

- `knowledge_id`：全库唯一，格式 `KP-YYYYMMDD-NNN`。
- `status`：`draft` / `reviewed` / `superseded` / `archived`。
- `evidence_level`：
  - `A`：现行正式标准、政策、受控原始实验记录或正式报告。
  - `B`：有明确作者、日期和原文定位的专家课件、会议纪要或二次整理。
  - `C`：口述、无日期笔记或未完成来源核对的内容，只可作为待核实线索。
- `source_locator`：必填；页码从 1 开始，表格要写工作表/行或记录编号。
- `next_review_at`：流程、联系人、政策和年度安排必须设复审日期。

## 入库门槛

以下任一情况不得标记为 `reviewed`：

- 找不到原文或无法给出页码/章节/记录号。
- 把整理者推断写成原文事实。
- 时效性信息没有复审日期。
- 与现有知识冲突但没有记录冲突及裁决人。
- 涉及正式育种、用鱼、用药、安全或对外申报，但未经负责人复核。

## 提交前检查

- [ ] 标题、日期、提交人和来源文件已填写。
- [ ] 每个关键数字和结论都有原文定位。
- [ ] 未把历史课件或专家意见当作当前法规。
- [ ] 敏感等级正确，公开版本已排除内部信息。
- [ ] 复审人、复审日期和下次复审日期已记录。
