# 鲲鹏知识库目录说明

这里是鲲鹏科研工作台的**知识源目录**。它与后台数据库中的“知识库”分开管理：目录保存原始/整理后的文件，后台数据库保存审核状态、权限、收藏和审计记录。

## 文件夹用途

| 文件夹 | 用途 | 是否自动进入知识库 |
| --- | --- | --- |
| `md/` | 已整理、准备供智能体检索的 Markdown 知识源 | 是。后台启动或执行同步时只新增缺失文件，不覆盖审核员已经修改过的条目 |
| `raw/` | 待整理的 Word、PDF、Excel、图片或原始文本 | 否。整理、排版并审核后，再复制为 Markdown 到 `md/` |
| `archive/` | 已废弃或历史版本，只保留备查 | 否 |

## 推荐流程

1. 新资料先放入 `raw/`，文件名写清楚主题和日期。
2. 整理为 UTF-8 Markdown，补充标题、来源、整理人和更新时间。
3. 将最终版本放入 `md/`。
4. 在 Windows 管理中心执行同步脚本；新文件会进入待审核/知识库，已有条目不会被源文件覆盖。
5. 审核员及以上角色在管理中心完成审核、排版和访问级别设置。
6. 被替换的旧版本移入 `archive/`，不要直接删除，以便追溯。

## 时效性规则

- `md/` 是本地可审计的知识源；后台数据库是实际权限和审核状态的权威记录。
- 同步采用“只新增、不覆盖”策略，避免自动同步抹掉审核员的编辑。
- 来源文件的更新时间、审核时间和最后同步时间在后台记录；发现旧内容时应提交新版本，而不是覆盖旧条目。
- 每次批量更新后，在管理中心点击刷新/同步并抽查新增条目。
