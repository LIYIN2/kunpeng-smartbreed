# 鲲鹏智育 · 智能育种决策与亲族选配

本技能用于亲族选育与选配决策支持。服务目标：抗病性、快速生长、成活率等目标协同提升，同时控制近交。

## 决策输入

必须确认的数据：

- 谱系文件（个体 ID、父本、母本、世代/批次）
- 基因型数据（标记平台、基因型矩阵；可选）
- 表型数据（目标性状及单位）
- 育种目标与经济权重（如抗病 0.4、生长 0.4、成活率 0.2）
- 约束条件（家系限制、近交上限、可用亲本数量、性别比例）
- 遗传参数（性状遗传力、遗传相关；缺失时提示使用文献估计并标注来源）

## 核心计算与指标

1. **近交系数（F）**：基于谱系用 Tabular 法计算（可用本仓库 tools/inbreeding.py）；无谱系时可用分子亲缘估计。
2. **亲缘关系**：个体间共祖系数（A 矩阵）或基因组亲缘矩阵（G 矩阵）。
3. **有效群体大小（Ne）**：基于谱系增量或分子数据估计，提示多样性风险。
4. **杂合度与多样性趋势**：观测/期望杂合度、等位基因丰富度随时间变化。
5. **育种值预测**：BLUP / GBLUP 等模型（由受控工作流执行），报告预测准确性。

## 选配方案生成

对每个候选配组输出：

- **候选亲本对**：个体 ID、性别、家系归属
- **预期子代遗传收益**：各目标性状的预期增益（基于育种值与遗传相关）
- **近交风险**：预期子代近交系数 ΔF，是否超过设定的近交上限
- **数据覆盖度**：该配组的表型/基因型数据完整度
- **不确定性说明**：遗传参数来源、模型假设、估计误差

生成多套方案（如保守型 / 平衡型 / 进取型），分别说明取舍，由专家选择。

## 决策原则

- 控制近交优先：任何方案不得突破设定的近交上限，除非用户明确授权并知晓风险。
- 解释优先：每个建议必须能解释"为什么这样配"，不接受黑箱输出。
- 专家终审：最终配组方案由领域专家确认后才进入实施；模型建议是辅助，不是决定。
- 年度反馈：选配结果与后代实测性状回测，用于校准遗传参数与模型。

## 边界

- 遗传参数与模型假设存疑时，明确标注并建议敏感性分析。
- 涉及珍稀亲本、濒危家系等敏感资源时，提示保护性策略（如优先保留多样性）。
