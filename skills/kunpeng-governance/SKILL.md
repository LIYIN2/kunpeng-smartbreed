# 鲲鹏智育 · 育种数据库与智能数据治理

本技能用于育种数据的标准化入库与质量治理，防止错误数据污染主库。

## 数据模型（以"个体"为中心）

核心实体：**个体**，关联：

- 亲本（父本、母本）
- 家系 / 繁育批次
- 样本（组织、采样时间、保存方式）
- 表型（性状、单位、测量时间、测量人）
- 基因型（标记平台、版本、基因型文件）
- 环境记录（养殖地点、水温、密度、饲料）
- 分析结果（QC、差异表达、GWAS、育种值等）

每个实体必须有唯一 ID，字段遵循字段字典（命名、类型、单位、允许值）。

## 基础质控规则

导入数据时逐项检查：

1. **重复个体**：同一 ID 出现多次，检查是否真重复（合并）还是错误（保留并标记）。
2. **谱系冲突**：个体 ID 与其亲本记录的父子关系矛盾（如性别冲突、世代倒挂）。
3. **缺失亲本**：谱系分析必需的亲本缺失时提示补充或标注未知。
4. **单位不一致**：同一性状在不同批次中单位不同（cm vs mm、g vs kg）时统一换算。
5. **异常值**：超出生物学合理范围的值（如负体重、超出 5 个标准差的极端值）标记复核。
6. **样本命名不一致**：同一样本的多种写法（大小写、分隔符、前后缀）归一化。

## 入库闭环（暂存—校验—审核—入库）

1. **暂存区**：导入的原始数据先进入暂存区，不直接进入主库。
2. **规则校验**：自动执行上述质控规则，输出问题清单（含行号/字段/原因/建议）。
3. **人工审核**：问题项由负责人确认（接受/修正/丢弃），关键参数与繁育决策必须人工审核。
4. **正式入库**：审核通过后写入主库，记录变更日志与审核人。

## 辅助要求

- 历史 Excel 数据通过标准模板导入，AI 辅助字段映射与异常检查，但映射结果须人工确认。
- 原始数据、中间文件、最终结果分层存储；主库保存结构化元数据与索引，大文件存对象存储/计算服务器。
- 定期备份；按角色设置只读、提交、审核、管理员权限，并保留访问与导出记录。
- 每次治理动作（映射、清洗、入库）留下审计记录：操作人、时间、变更内容、依据。
