# GWAS 白名单流程

1. 样本/标记 QC：缺失、MAF、杂合度、亲缘、批次、重复与参考等位基因；阈值项目化并报告过滤前后数量。
2. 表型诊断：分布、异常值、转换依据、固定效应和重复测量结构。
3. 群体结构：PCA、亲缘矩阵与亚群检查；模型必须匹配群体结构。
4. 关联：使用经准入的线性/广义线性混合模型；记录软件、版本、公式、协变量与随机效应。
5. 校准：QQ 图、通胀指标、多重检验阈值和敏感性分析。
6. 注释：按一致的参考基因组定位候选区域，报告效应等位基因、频率、效应量、标准误/P 值和证据边界。

完整交付至少含 QC 报告、对齐清单、PCA/亲缘结果、完整关联表、Manhattan/QQ 图、模型配置、日志和候选区域表。
