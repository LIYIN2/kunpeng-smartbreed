# SCI 投稿包工作流

本规范依据李寅 2026-03-21 整理稿提炼，并修正其中不能通用于所有期刊的经验性规则。原稿作为内部知识来源，不替代目标期刊最新版 Guide for Authors。

## 1. 先建立期刊要求快照

记录期刊、文章类型、指南 URL、核验日期、字数、结构、图表格式、Highlights、补充材料、匿名审稿、数据政策和声明要求。要求变动时保留旧快照，不覆盖历史投稿记录。

## 2. 投稿包清单

- Manuscript：题目、作者/机构、摘要、关键词、正文、致谢、基金、参考文献和图表，是否合并由期刊指南决定。
- Cover Letter：题目、稿件类型、研究问题、核心方法/发现、期刊契合度及作者确认的一稿一投/原创声明。不要堆砌未经证实的“首次”“突破”。
- Highlights：仅在期刊要求时提供；数量和每条字符限制读取目标期刊规则，不默认 150 字符。
- CRediT Author Statement：按期刊接受的 CRediT taxonomy 术语逐作者登记，并由全体作者确认；不由模型猜贡献。
- Competing Interests：先询问真实利益关系；仅在作者确认不存在时使用无利益冲突声明。
- Ethics / permits、Funding、Data/Code availability、Author agreement：按研究和期刊要求逐项核对。
- Response to Reviewers：返修时逐条保留评论原文、回应、修改位置和未采纳理由。

## 3. 正文证据链

- Results：每个小节绑定真实图表/统计表，客观报告效应量、不确定性、统计检验与阴性结果；避免把解释写成观察结果。
- Materials and Methods：每张结果图表反向对应实验设计、样本、处理、测量、软件/版本、参数和统计模型。水产研究补齐物种、品系/世代、水温、盐度、密度、饲喂、伦理/许可等实际信息；未知项写 `待确认`。
- Discussion：关键结果 + 可核验文献 + 作者分析，分开相关性、机制解释和对大黄鱼的推断；不得扩大外推。
- Introduction：背景 → 已知证据 → 明确缺口 → 研究目的/假设；不提前展开结果。

## 4. 图表与格式

先查目标期刊要求再设置尺寸、字体、分辨率、色彩模式和文件类型。R/Illustrator 的个人参数只能作为起点，不能替代期刊规范。图表、正文引用、图例、统计符号、单位和样本量必须互相一致。

## 5. 完成门禁

1. 所有数值能回溯至数据/结果文件，文献能回溯至 DOI 或正式页面。
2. 作者姓名、顺序、机构、通讯作者、CRediT、基金和声明经作者确认。
3. 期刊要求逐项通过，未知项显式标记。
4. DOCX/PDF 渲染后逐页检查；图表清晰、编号和交叉引用一致。
5. 输出 submission manifest：文件名、版本、校验和、负责人、审核状态和提交日期。
