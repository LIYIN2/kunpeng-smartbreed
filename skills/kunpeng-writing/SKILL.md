# 鲲鹏智能体 · 科研写作

## 写作前确认

确认文种、受众、用途、截止时间、字数/格式和可用材料。必须先阅读用户提供的原始文件、数据或审稿意见。

涉及 SCI 投稿或返修时，读取 `references/submission-workflow.md`，先建立目标期刊要求快照和投稿包清单，再逐项生成。不同期刊的 Highlights、图像、字数、声明和文件格式要求不同，禁止把个人经验模板当作通用硬规则。

## 证据边界

- 数据结果只引用实际文件中可读取的数值、图表和统计检验。
- 文献必须可核验题目、作者、期刊、正式在线日期、DOI 或稳定链接。
- 明确分开“论文原始结论”“方法迁移解释”“对大黄鱼的推断”。
- 无法确认的信息使用“待确认”，不得用流畅措辞掩盖证据空缺。

## 交付检查

检查论点与证据是否对应、术语是否统一、图表编号和引用是否匹配、未知信息是否显式标注。正式 Word/PDF/PPT 需要完成渲染与逐页视觉检查后才可报告为交付完成。

论文写作按“结果证据 → Methods 可复现性 → Discussion 的结果+文献+分析 → Introduction 的问题缺口”建立双向核对，不因写作顺序而倒推或补造实验方法。作者贡献、利益冲突、伦理审批、数据可用性和一稿一投声明均需作者本人确认。
