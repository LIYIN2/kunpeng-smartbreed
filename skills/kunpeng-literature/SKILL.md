# 鲲鹏智育 · 文献知识检索与问答

本技能用于大黄鱼遗传育种相关的文献知识服务。核心原则：**先检索，后回答；无证据，不臆造**。

## 检索流程

1. 解析问题：识别主题（基因 / 性状 / 病原 / 标记 / 策略）、物种（确认是大黄鱼 *Larimichthys crocea* 还是近缘种）、时间范围与证据类型要求。
2. 检索语料：优先检索已建立的文献语料库（论文、摘要、补充材料、内部规范）；必要时补充外部检索（PubMed、Web of Science 等），并记录检索式。
3. 证据筛选：按相关性、实验设计质量（样本量、对照、统计方法）、发表时间排序。
4. 生成回答：先给结论，再给证据链（证据类型 → 实验方法 → 结论强度 → 来源）。

## 输出格式（结构化）

对每个结论给出：

- **候选基因 / 性状 / 标记**：名称与物种
- **证据类型**：分子实验 / 遗传连锁 / 关联分析 / 综述 / 模型预测
- **实验方法**：简要方法说明
- **结论强度**：强（多研究一致 + 功能验证）/ 中 / 弱（单研究或间接证据）
- **来源**：论文题目、DOI、原文片段（引用时保留原文）
- **多维标签**：基因、性状、病原、组织、研究方法、年份

## 证据不足与冲突处理

- 检索不到直接证据：回答"尚无充分证据"，并说明已检索的范围与可能的扩展方向，不推断。
- 文献结论冲突：并列展示各结论及其实验背景，指出分歧点（物种差异、群体差异、方法差异），不下绝对结论。
- 引用必须是真实存在的文献；无法确认来源时如实说明"该表述来自模型知识，未在语料中核实"，并建议人工核验。

## 常见主题提示

- 抗病基因：关注免疫相关基因（如 MHC、TLR、干扰素通路）在大黄鱼中的报道。
- 生长性状：关注生长激素/IGF 轴、肌肉生长相关基因与 QTL。
- 病原挑战：注意区分体内攻毒、细胞系实验与野外流行病学证据。
- 分子标记：区分 SNP / SSR / InDel 及标记-性状关联的验证状态。

## 边界

- 本技能提供证据引用与知识服务，不替代实验验证；关键结论用于科研决策前需人工复核。
- 若用户提供 PDF/文本语料，先解析建立可检索片段索引，再执行上述流程。
